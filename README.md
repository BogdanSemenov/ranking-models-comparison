# Промпт для Claude Code

## Задача

Создай веб-страницу для сравнения двух моделей ранжирования товарных подборок и опубликуй её на GitHub Pages.

## Контекст

Это инструмент для демонстрации результатов A/B-теста ранжирования в e-commerce. Страница показывает side-by-side сравнение выдачи двух моделей: текущей (baseline) и новой (challenger).

## Структура проекта
```template/   — скриншоты из приложения (р
data/       — CSV-файлы с результатами ранжирования
  current_model.csv  — выдача текущей модели
  new_model.csv      — выдача новой модели
photo/      — фотографии товаров в формате {art_code}_Фото Товара_Л.jpeg
```
## Требования

### 1. Дизайн и layout

- Страница с двумя колонками: слева — Current Model, справа — New Model
- Дизайн карточек товаров должен максимально повторять визуал из скриншотов в template/ — изучи их внимательно и воспроизведи стиль
- Карточки должны содержать: фото товара, название, цену, рейтинг (звёзды)
- Адаптивная вёрстка, приятный UI

### 2. Данные

- Прочитай CSV-файлы data/current_model.csv и data/new_model.csv — разберись в структуре колонок
- Каждый CSV описывает упорядоченный список товаров (результат ранжирования)
- Для подборок/категорий используй соответствующее поле из CSV как заголовок секции

### 3. Фотографии товаров

- Фото лежат в photo/ в формате {art_code}_Фото Товара_Л.jpeg
- Используй ТОЛЬКО файлы с суффиксом `_Л` (лицевая сторона). Остальные варианты фото игнорируй
- Матчинг фото к товару — по art_code из CSV
- Если фото не найдено — покажи placeholder

### 4. Бейдж Adtech

- В CSV есть колонка is_adtech (или аналогичная булева/флаговая колонка)
- Товары с is_adtech = true/1 должны иметь небольшой бейдж “Adtech” на карточке (например, в верхнем углу фото)

### 5. Рейтинг

- Отображай только оценку (звёзды или число). НЕ показывай количество отзывов
- Если у товара нет оценки (пустое значение / null / 0) — не отображай блок рейтинга вообще

### 6. Публикация на GitHub Pages

- Инициализируй git-репозиторий
- Создай remote на GitHub (используй gh CLI)
- Запуши код и включи GitHub Pages (ветка main, папка / (root) или `/docs`)
- Фотографии товаров тоже должны быть в репозитории и отображаться на странице
- Убедись, что страница доступна по URL и работает корректно

## Технические ограничения

- Статический сайт (HTML + CSS + JS), без серверной части
- Данные из CSV можно вшить в JS как JSON на этапе сборки, либо подгружать fetch’ем
- Фото копируй в папку сайта с сохранением связи по art_code
