# Сравнение моделей в категориальном ранжировании

Инструмент для визуального сравнения выдачи двух моделей категориального ранжирования товарных подборок.

**Demo:** https://bogdansemenov.github.io/ranking-models-comparison/

## Описание

Страница разделена на две панели для side-by-side сравнения:
- **Текущая модель (A)** — левая панель
- **Новая модель (B)** — правая панель

Выбор подборки (категории) через выпадающий список — данные фильтруются по `art_category_level_2_name`.

## Функциональность

- Разделённый экран с общим скроллом
- Выпадающий список для выбора подборки (категории)
- Карточки товаров с изображениями, ценами, скидками и рейтингом
- Бейдж "ad" для рекламных товаров (`is_adtech=True`)
- Адаптивная вёрстка (4 → 3 → 2 колонки на панель)

## Формат данных CSV

| Колонка | Описание |
|---------|----------|
| `art_code` | Артикул товара |
| `product_name` | Название товара |
| `position` | Позиция в выдаче |
| `rating_value` | Рейтинг (например, 4.9) |
| `art_category_level_2_name` | Категория/подборка |
| `link` | Ссылка на товар |
| `is_adtech` | Флаг рекламного товара (True/False) |
| `image` | URL изображения товара |
| `base_price` | Базовая цена |
| `action_price` | Акционная цена (если есть) |
