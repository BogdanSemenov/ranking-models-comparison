# Ranking Models Comparison

Веб-страница для сравнения двух моделей ранжирования товарных подборок в e-commerce.

**Demo:** https://bogdansemenov.github.io/ranking-models-comparison/

## Описание

Инструмент для демонстрации результатов A/B-теста ранжирования. Страница показывает сравнение выдачи двух моделей с переключением между ними:
- **Current Model (A)** — текущая модель (baseline)
- **New Model (B)** — новая модель (challenger)

Дизайн полностью повторяет стиль сайта magnit.ru.

## Структура проекта

```
├── data/                    # CSV-файлы с результатами ранжирования
│   ├── current_model.csv    # Выдача текущей модели
│   └── new_model.csv        # Выдача новой модели
├── docs/                    # Статический сайт для GitHub Pages
│   ├── index.html           # Главная страница
│   ├── styles.css           # Стили (дизайн Магнит)
│   ├── app.js               # Логика загрузки и отображения данных
│   └── data/                # Копия CSV для сайта
├── template/                # Примеры дизайна из приложения Магнит
└── README.md
```

## Формат данных CSV

| Колонка | Описание |
|---------|----------|
| `art_code` | Артикул товара |
| `product_name` | Название товара |
| `position` | Позиция в выдаче |
| `rating_value` | Рейтинг (например, 4.9) |
| `art_category_level_2_name` | Категория/подборка |
| `link` | Ссылка на товар в magnit.ru |
| `is_adtech` | Флаг рекламного товара (True/False) |
| `image` | URL изображения товара |
| `base_price` | Базовая цена |
| `action_price` | Акционная цена (если есть) |

## Функциональность

- Переключение между моделями A и B
- Загрузка изображений товаров по URL из колонки `image`
- Переход на страницу товара по ссылке из колонки `link`
- Отображение бейджа "Промокод: РУБЛЬ" для рекламных товаров
- Показ скидки при наличии акционной цены
- Рейтинг со звездой
- Кнопка "В корзину"
- Адаптивная верстка (4 → 3 → 2 колонки)
